# Checklist

## 视觉基础
- [x] 玻璃面板颜色呈垂直渐变：底层蓝、中层紫、顶层金，不再循环五色
- [x] 仅保留两组光源（顶部紫 + 底部蓝），无黄色光源
- [x] 正面项目面板与右侧部门面板材质风格有明显视觉区分

- [x] 点击任意楼层面板，相机在 ~1 秒内平滑移动到目标位置

- [x] 浮动楼层标签始终面向相机（Billboard），旋转视角后文字可读
- [x] 左下角有三个视角书签按钮（正面/右侧/CEO），点击可快速切换
- [x] 鼠标悬浮面板时浮现轻量预摘要卡片
