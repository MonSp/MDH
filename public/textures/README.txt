# PBR 贴图说明

此目录用于存放从 ambientCG.com 下载的 CC0 免费 PBR 贴图。
代码中的 PBRTextureLoader 会尝试加载这些贴图，若文件缺失则自动 fallback 到 Canvas 程序化纹理。
