# F1: 范式谱系与学术证据（经验/CoT/workflow → 可执行程序）

## Findings

### [1] Voyager (2023) 首次确立"技能库=可执行代码"的学术谱系起点，用代码而非文本规则累积技能并显著优于先前方法
- quote: "an ever-growing skill library of executable code for storing and retrieving complex behaviors ... The skills developed by Voyager are temporally extended, interpretable, and compositional, which compounds the agent's abilities rapidly and alleviates catastrophic forgetting."
- url: https://arxiv.org/abs/2305.16291
- source_type: primary
- published: 2023-05-25 (v2: 2023-10-19)
- confidence: high

### [2] Agent Workflow Memory (AWM) 证明"从经验归纳可复用 workflow"可量化提效：Mind2Web/WebArena 相对成功率 +24.6%/+51.1%，且在线归纳可跨任务/站点/域泛化
- quote: "we introduce Agent Workflow Memory (AWM), a method for inducing commonly reused routines, i.e., workflows, and selectively providing workflows to the agent to guide subsequent generations. ... AWM substantially improves the baseline results by 24.6% and 51.1% relative success rate on Mind2Web and WebArena while reducing the number of steps taken to solve WebArena tasks successfully."
- url: https://arxiv.org/abs/2409.07429
- source_type: primary
- published: 2024-09-11
- confidence: high

### [3] AFlow 将 workflow 优化重构为"代码表示的 workflow"上的搜索问题，用 MCTS 经执行反馈迭代改代码，平均超 SOTA 5.7%，并让小模型以 GPT-4o 4.55% 的推理美元成本在特定任务上反超
- quote: "we reformulate workflow optimization as a search problem over code-represented workflows, where LLM-invoking nodes are connected by edges. We introduce AFlow, an automated framework that efficiently explores this space using Monte Carlo Tree Search, iteratively refining workflows through code modification, tree-structured experience, and execution feedback. ... AFlow enables smaller models to outperform GPT-4o on specific tasks at 4.55% of its inference cost in dollars."
- url: https://arxiv.org/abs/2410.10762
- source_type: primary
- published: 2024-10-14 (v4: 2025-04-15)
- confidence: high

### [4] SkillWeaver (2025-04) 把"开放创造中总结经验固化为程序"做成闭环：agent 自主发现技能、练习、把练习经验蒸馏为可复用 API 库，WebArena 相对成功率 +31.8%、真实站点 +39.8%，强者技能移植给弱者最高 +54.3%
- quote: "the agent autonomously discovers skills, executes them for practice, and distills practice experiences into robust APIs. Iterative exploration continually expands a library of lightweight, plug-and-play APIs, significantly enhancing the agent's capabilities."
- url: https://arxiv.org/abs/2504.07079
- source_type: primary
- published: 2025-04-09
- confidence: high

### [5] Agent Skills 开放标准（agentskills.io，Anthropic 于 2025-12-18 发布为开放标准）把 `scripts/` 可执行代码作为技能一等组成部分，配三层渐进披露（discovery → activation → execution），已获 Claude Code、Cursor、GitHub Copilot、Gemini CLI、OpenAI Codex、VS Code、Goose、OpenHands 等数十款产品采用
- quote: "my-skill/ ├── SKILL.md          # Required: metadata + instructions ├── scripts/          # Optional: executable code ├── references/       # Optional: documentation ... 3. **Execution**: The agent follows the instructions, optionally executing bundled code or loading referenced files as needed."
- url: https://agentskills.io
- source_type: primary
- published: 2025-12-18 (开放标准发布，Anthropic 博客 Update 标注)
- confidence: high

### [6] DSPy 以"编译"为名给出 compilation 论述的代表作：把声明式 LM 调用抽象为计算图并由 compiler 针对指标优化，GPT-3.5/llama2-13b 编译后超标准少样本提示 25%/65%
- quote: "We design a compiler that will optimize any DSPy pipeline to maximize a given metric. ... a few lines of DSPy allow GPT-3.5 and llama2-13b-chat to self-bootstrap pipelines that outperform standard few-shot prompting (generally by over 25% and 65%, respectively)"
- url: https://arxiv.org/abs/2310.03714
- source_type: primary
- published: 2023-10-05
- confidence: high

### [7] Anthropic 官方工程博客给出"固化为代码"的经济学与确定性论据：token 生成排序远贵于执行排序算法，且许多场景只接受代码的确定性可靠性
- quote: "Large language models excel at many tasks, but certain operations are better suited for traditional code execution. For example, sorting a list via token generation is far more expensive than simply running a sorting algorithm. Beyond efficiency concerns, many applications require the deterministic reliability that only code can provide."
- url: https://www.anthropic.com/engineering/equipping-agents-for-the-real-world-with-agent-skills
- source_type: primary
- published: 2025-10-16
- confidence: high

### [8] Anthropic 官方技能迭代方法即"LLM 执行中总结经验→固化为可执行代码"回路：任务后让 Claude 把成功做法与常见错误写进技能的可复用上下文与代码，跑偏时自我反思
- quote: "Iterate with Claude: As you work on a task with Claude, ask Claude to capture its successful approaches and common mistakes into reusable context and code within a skill. If it goes off track when using a skill to complete a task, ask it to self-reflect on what went wrong."
- url: https://www.anthropic.com/engineering/equipping-agents-for-the-real-world-with-agent-skills
- source_type: primary
- published: 2025-10-16
- confidence: high

### [9] Anthropic 明确把"agent 自行创建、编辑、评估技能并把自身行为模式固化为可复用能力"列为 Skills 的下一步路线图
- quote: "Looking further ahead, we hope to enable agents to create, edit, and evaluate Skills on their own, letting them codify their own patterns of behavior into reusable capabilities."
- url: https://www.anthropic.com/engineering/equipping-agents-for-the-real-world-with-agent-skills
- source_type: primary
- published: 2025-10-16
- confidence: high

### [10] Experience Compression Spectrum (2026-04) 用定量谱系支持"文本规则让位于技能/程序"：episodic memory 压缩 5–20×、procedural skills 50–500×、declarative rules 1000×+；22 篇主文献 1,136 条引用的社区交叉引用率 <1%，且 20+ 系统全部固定压缩级、无跨级自适应（missing diagonal）
- quote: "We propose the Experience Compression Spectrum, a unifying framework that positions memory, skills, and rules as points along a single axis of increasing compression (5--20$\\times$ for episodic memory, 50--500$\\times$ for procedural skills, 1{,}000$\\times$+ for declarative rules), directly reducing context consumption, retrieval latency, and compute overhead."
- url: https://arxiv.org/abs/2604.15877
- source_type: primary
- published: 2026-04-17 (v2: 2026-06-25)
- confidence: high

### [11] "Agent in a Bottle"（2026-10）提出 bottling 概念＝把通用能力转化为平衡质量与摊销成本的任务专用解（含"写可复用程序"），实测 Opus 5 在查询-商品相关性分类上以约 657× 更低成本保留约 82% 零样本 macro-F1
- quote: "We call this ability \"bottling\": the ability to turn general capabilities into task-specific solutions that balance answer quality and amortised cost. ... Agents choose their own approach, such as training a small model or writing a reusable program. ... on query-product relevance classification, Opus 5 retains about 82% of its zero-shot macro-F1 at roughly 657 times lower reported cost."
- url: https://arxiv.org/abs/2610.08775
- source_type: primary
- published: 2026-10-06
- confidence: high

### [12] 同一 BOTTLED 基准给出关键否定证据：固化能力不随零样本能力自动获得——60 次固化运行中 48 次低于其模型零样本表现 95% 置信区间下界、31 次不敌同 token 预算的小模型蒸馏基线
- quote: "strong zero-shot task performance does not reliably translate into strong bottling capabilities. ... 48 of 60 bottling runs score below the lower bound of the 95% confidence interval of their model's zero-shot performance. Moreover, 31 of 60 runs underperform the stronger of two small-model distillation baselines with the same token budget."
- url: https://arxiv.org/abs/2610.08775
- source_type: primary
- published: 2026-10-06
- confidence: high
