# F3: 业界生产实践

## Findings

### [1] Anthropic 的 Agent Skills 官方定位是"指令+脚本+资源"的文件夹，且明确主张"可执行代码比 token 生成更可靠"的场景应固化为程序
- quote: "Skills are folders that include instructions, scripts, and resources that Claude can load when needed." / "Powerful: Skills can include executable code for tasks where traditional programming is more reliable than token generation."
- url: https://www.anthropic.com/news/skills
- source_type: primary
- published: 2025-10-16（页面标注 Category: Announcements, Date October 16, 2025；2025-12-18 更新注明 Agent Skills 成为开放标准 agentskills.io）
- confidence: high

### [2] Anthropic 工程博客给出固化为代码的直接理由：确定性/可重复性，并展望"智能体自己把行为模式固化为 Skill"
- quote: "many applications require the deterministic reliability that only code can provide." / "because code is deterministic, this workflow is consistent and repeatable." / "we hope to enable agents to create, edit, and evaluate Skills on their own, letting them codify their own patterns of behavior into reusable capabilities."
- url: https://www.anthropic.com/engineering/equipping-agents-for-the-real-world-with-agent-skills
- source_type: primary
- published: 2025-10-16
- confidence: high

### [3] Anthropic 工程博客给出"从执行经验中提炼固化"的操作方法：让 Claude 把成功做法与常见错误写回 Skill，通过自反思迭代而非预先写全规则
- quote: "As you work on a task with Claude, ask Claude to capture its successful approaches and common mistakes into reusable context and code within a skill. If it goes off track when using a skill to complete a task, ask it to self-reflect on what went wrong. This process will help you discover what context Claude actually needs, instead of trying to anticipate it upfront."
- url: https://www.anthropic.com/engineering/equipping-agents-for-the-real-world-with-agent-skills
- source_type: primary
- published: 2025-10-16
- confidence: high

### [4] Claude Code 内置"把跑通的启动/验证流程录制成技能"的机制：/run-skill-generator 与 /verify 会把实际生效的命令固化为仓库内 SKILL.md，后续运行不再靠 LLM 重新摸索
- quote: "/run-skill-generator records the recipe instead. It gets your app running from a clean environment, captures what worked (the install commands, the env vars, the launch script), and commits it as a per-project skill at `.claude/skills/run-<name>/`. After that, /run, /verify, and any other agent in the repo follow the recorded recipe instead of rediscovering it." / "Claude edits the recorded file only when it steered a run wrong… so you can commit the file without per-session diffs."
- url: https://code.claude.com/docs/en/skills
- source_type: primary
- published: unknown（文档含 Claude Code v2.1.286+ 等版本约束，抓取于 2026-10）
- confidence: high

### [5] Claude Code 官方文档区分"始终加载的指令 (CLAUDE.md)"与"按需加载的程序化技能 (skills)"，并把 custom commands 全部并入 skills，指示"当你反复粘贴同一段流程时就该固化为 skill"
- quote: "Create a skill when you keep pasting the same instructions, checklist, or multi-step procedure into chat, or when a section of CLAUDE.md has grown into a procedure rather than a fact. Unlike CLAUDE.md content, a skill's body loads only when it's used" / "Custom commands have been merged into skills."
- url: https://code.claude.com/docs/en/skills
- source_type: primary
- published: unknown（抓取于 2026-10）
- confidence: high

### [6] AGENTS.md 已成为跨产品通用的"给智能体的 README"，被 60k+ 开源仓库采用并由 Linux 基金会 Agentic AI Foundation 托管；且文档明确要求 agent 实际执行其中的程序化检查
- quote: "A simple, open format for guiding coding agents, used by over 60k open-source projects." / "AGENTS.md is now stewarded by the Agentic AI Foundation under the Linux Foundation." / "Will the agent run testing commands found in AGENTS.md automatically? Yes—if you list them. The agent will attempt to execute relevant programmatic checks and fix failures before finishing the task." / "at time of writing the main OpenAI repo has 88 AGENTS.md files."
- url: https://agents.md/
- source_type: primary（AGENTS.md 规范官方站）
- published: unknown（页面提及 Agentic AI Foundation 声明链接 openai.com/index/agentic-ai-foundation）
- confidence: high

### [7] Cursor 官方文档主张 Rules"打包提示词与脚本"，并明确把可确定性执行的检查外置为 linter 而非写进规则文本；规则按"agent 反复犯同一错误"才增量沉淀
- quote: "Rules provide system-level instructions to Agent. They bundle prompts, scripts, and more together, making it easy to manage and share workflows across your team." / "Copying entire style guides: Use a linter instead." / "Start simple. Add rules only when you notice Agent making the same mistake repeatedly." / "When you see Agent make a mistake, update the rule. You can even tag @cursor on a GitHub issue or PR to have Agent update the rule for you."
- url: https://cursor.com/docs/context/rules
- source_type: primary
- published: unknown（抓取于 2026-10）
- confidence: high

### [8] Devin（Cognition）将 SKILL.md 提交进仓库作为可复用流程，并内置"会话后自动建议沉淀技能"闭环：Devin 学到新东西后生成 SKILL.md 提案、一键开 PR 入库
- quote: "Skills are SKILL.md files you commit to your repositories that teach Devin reusable procedures — any repeatable workflow you want Devin to follow consistently." / "After Devin tests your application or learns something new about your setup during a session, it will suggest creating or updating a skill to capture that knowledge… A summary of what was learned… The proposed SKILL.md file contents… A 'Create PR' button to commit the skill to your repo." / "Without skills, Devin has to figure out workflows from scratch every session."
- url: https://docs.devin.ai/product-guides/skills.md
- source_type: primary
- published: unknown（抓取于 2026-10）
- confidence: high

### [9] Devin 官方明确区分两类沉淀物：skills（仓库内、版本控制的可执行流程）vs playbooks（web 应用内、可共享的提示词模板）——"程序型沉淀"与"提示词型沉淀"被产品化为两个不同对象
- quote: "Skills vs. Playbooks: Skills — In your repo as SKILL.md files — version-controlled alongside your code; Playbooks — In the Devin web app — managed through the UI… Best for: Skills: Testing procedures, local dev setup, deployment checklists, repo-specific workflows; Playbooks: Reusable prompt templates, cross-repo task patterns, onboarding guides."（"Skills are procedures you write deliberately. Memory is what Devin learns about your preferences and projects as you work"）
- url: https://docs.devin.ai/product-guides/skills.md
- source_type: primary
- published: unknown（抓取于 2026-10）
- confidence: high

### [10] Devin Dynamic Workflows 把多智能体编排本身固化为确定性 Python 脚本，跑通后可作为 skill（workflow.py + SKILL.md）入库复跑——"编排即代码"，且脚本有可回放/可恢复的确定性约束
- quote: "a dynamic workflow is a deterministic Python script that orchestrates a team of Devin agents." / "In a workflow, the orchestration itself is code." / "Once a workflow works, it can be committed to your repo as a skill: a workflow.py next to a SKILL.md describing when to use it. Devin then discovers and reruns it on future tasks instead of authoring a new script." / "Workflow logic and prompts must not depend on the current time or date, randomness, generated IDs, environment variables, filesystem state, or network responses."
- url: https://docs.devin.ai/work-with-devin/dynamic-workflows.md
- source_type: primary
- published: unknown（抓取于 2026-10）
- confidence: high

### [11] Anthropic《Building Effective Agents》定义 workflow 为"LLM 与工具沿预定义代码路径编排"，并给出 evaluator-optimizer 循环（LLM 生成+LLM 审阅迭代）作为标准生产模式；SWE-bench 实践中投入优化工具（程序侧）多于优化提示词
- quote: "Workflows are systems where LLMs and tools are orchestrated through predefined code paths." / "While building our agent for SWE-bench, we actually spent more time optimizing our tools than the overall prompt." / evaluator-optimizer: "one LLM call generates a response while another provides evaluation and feedback in a loop."
- url: https://www.anthropic.com/research/building-effective-agents
- source_type: primary
- published: 2024-12-19
- confidence: high

### [12] Qodo（2026-02）发布"评审→自动修复"的 skill 式 runbook 并实测：审查问题带 agent prompt/位置/严重级结构化上下文，agent 循环批量修复并回帖，一次 PR 8 个待修问题（2 HIGH/3 MEDIUM/3 LOW）几乎全部解决
- quote: "Qodo recently shipped agent skills, purpose-built capabilities that bring code review assistance directly into your AI coding agent." / "I chose 'Auto-fix all,' and the skill started working through the issues starting with the highest priority security findings first. Claude Code ran on a loop addressing each issue… and making commits per issue." / "Compatible with Claude Code, Cursor, Windsurf, Cline, and any agent supporting the open Agent Skills standard."
- url: https://www.qodo.ai/blog/how-i-use-qodos-agent-skills-to-auto-fix-issues-in-pull-requests/
- source_type: secondary（厂商工程博客，含真实 PR #49/#50 实验数据）
- published: 2026-02-18
- confidence: medium

### [13] Agent Skills 开放标准（Anthropic 发起，2025-12-18 转开放）已被 40+ 主流产品实现，包括 ChatGPT/Codex、GitHub Copilot、VS Code、Gemini CLI、Cursor、JetBrains Junie、Factory 等——"可执行工件沉淀"格式已成跨厂商事实标准
- quote: "The Agent Skills format was originally developed by Anthropic, released as an open standard, and has been adopted by a growing number of agent products." / "Repeatable workflows: Turn multi-step tasks into consistent, auditable procedures."（Client Showcase 列出 ChatGPT & Codex、GitHub Copilot、VS Code、Gemini CLI、Cursor、Amp、Goose、OpenHands、Factory、Junie、Snowflake Cortex Code 等）
- url: https://agentskills.io/
- source_type: primary（开放标准官方站）
- published: unknown（Anthropic 侧注明 2025-12-18 发布为开放标准）
