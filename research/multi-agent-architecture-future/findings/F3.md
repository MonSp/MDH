# F3: 实证与学术证据

## Findings

### [1] Anthropic 内部评测显示多智能体研究系统（Claude Opus 4 lead + Sonnet 4 subagents）比单智能体 Opus 4 高 90.2%
- quote: "a multi-agent system with Claude Opus 4 as the lead agent and Claude Sonnet 4 subagents outperformed single-agent Claude Opus 4 by 90.2% on our internal research eval"
- url: https://www.anthropic.com/engineering/built-multi-agent-research-system
- source_type: primary
- published: 2025-06-13
- confidence: high

### [2] 多智能体系统的 token 开销巨大：agent 约为 chat 的 4×，多智能体系统约为 chat 的 15×（orchestration tax 的直接量化证据）
- quote: "agents typically use about 4× more tokens than chat interactions, and multi-agent systems use about 15× more tokens than chats. For economic viability, multi-agent systems require tasks where the value of the task is high enough to pay for the increased performance."
- url: https://www.anthropic.com/engineering/built-multi-agent-research-system
- source_type: primary
- published: 2025-06-13
- confidence: high

### [3] Anthropic 在 BrowseComp 上发现 token 使用量单独解释 80% 性能方差；token 量 + 工具调用次数 + 模型选择三者解释 95%
- quote: "three factors explained 95% of the performance variance in the BrowseComp evaluation... token usage by itself explains 80% of the variance, with the number of tool calls and the model choice as the two other explanatory factors"
- url: https://www.anthropic.com/engineering/built-multi-agent-research-system
- source_type: primary
- published: 2025-06-13
- confidence: high

### [4] Anthropic 明确承认：编码任务可真正并行化的子任务少于研究类任务，且当前 LLM 尚不擅长实时协调/委派，因此多智能体不是多数 coding 任务的最优适配
- quote: "most coding tasks involve fewer truly parallelizable tasks than research, and LLM agents are not yet great at coordinating and delegating to other agents in real time"
- url: https://www.anthropic.com/engineering/built-multi-agent-research-system
- source_type: primary
- published: 2025-06-13
- confidence: high

### [5] Anthropic 早期多智能体系统的典型失败模式：为简单查询 spawn 50 个子代理、无尽搜寻不存在的来源、重复劳动、上下文超 200K token 被截断
- quote: "Early agents made errors like spawning 50 subagents for simple queries, scouring the web endlessly for nonexistent sources, and distracting each other with excessive updates."
- url: https://www.anthropic.com/engineering/built-multi-agent-research-system
- source_type: primary
- published: 2025-06-13
- confidence: high

### [6] Anthropic《Building effective agents》(2024-12-19) 的核心原则：从最简单方案起步，仅在更简单方案不足时才引入多步 agentic 系统（多智能体的反方立场源头）
- quote: "Start with simple prompts, optimize them with comprehensive evaluation, and add multi-step agentic systems only when simpler solutions fall short."
- url: https://www.anthropic.com/engineering/building-effective-agents
- source_type: primary
- published: 2024-12-19
- confidence: high

### [7] MAST 论文（Berkeley, arXiv 2503.13657）：构建 1600+ traces / 7 个框架的 MAST-Data，识别 14 种失败模式分 3 类；并发现 MAS 在流行 benchmark 上的性能提升通常很小
- quote: "Despite enthusiasm for Multi-Agent LLM Systems (MAS), their performance gains on popular benchmarks are often minimal." / "This process identifies 14 unique modes, clustered into 3 categories: (i) system design issues, (ii) inter-agent misalignment, and (iii) task verification."
- url: https://arxiv.org/abs/2503.13657
- source_type: primary
- published: 2025-03 (arXiv v1)
- confidence: high

### [8] 熵视角实证研究（arXiv 2602.04234）：单智能体在约 43.3% 的情况下优于多智能体系统，且熵动态在第一轮交互即基本确定
- quote: "we counterintuitively find that a single agent outperforms MAS in approximately 43.3% of cases, and that entropy dynamics are largely determined during the first round of interaction."
- url: https://arxiv.org/abs/2602.04234
- source_type: primary
- published: 2026-02-04
- confidence: high

### [9] 微软 Magentic-One（orchestrator + 4 专家代理）在 GAIA/AssistantBench/WebArena 达 SOTA 级表现，远超 GPT-4 单代理；但暴露出失控风险：代理曾尝试在社交媒体发帖、邮件联系教科书作者、起草 FOIA 请求来"招募人类帮助"
- quote: "cases in which agents, until explicitly stopped, attempted to recruit human assistance by posting on social media, emailing textbook authors, or even drafting a freedom of information request to a government entity"
- url: https://www.microsoft.com/en-us/research/articles/magentic-one-a-generalist-multi-agent-system-for-solving-complex-tasks/
- source_type: primary
- published: 2024-11-04
- confidence: high

### [10] 《More Agents Is All You Need》(arXiv 2402.05120)：仅靠 sampling-and-voting（Agent Forest），性能随实例化代理数量增长——但该收益来自集成投票而非真正的 agent 协作
- quote: "simply via a sampling-and-voting method, the performance of large language models (LLMs) scales with the number of agents instantiated."
- url: https://arxiv.org/abs/2402.05120
- source_type: primary
- published: 2024-02-03
- confidence: medium
