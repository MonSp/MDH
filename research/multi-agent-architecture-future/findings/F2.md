# F2: 基础设施协议与互操作

## Findings

### [1] MCP 由 Anthropic 于 2024-11-25 开源，定位是连接 AI 助手与数据/工具系统的"通用开放标准"，首批采用者包括 Block、Apollo 与开发工具商 Zed、Replit、Codeium、Sourcegraph
- quote: "Today, we're open-sourcing the Model Context Protocol (MCP), a new standard for connecting AI assistants to the systems where data lives... Early adopters like Block and Apollo have integrated MCP into their systems, while development tools companies including Zed, Replit, Codeium, and Sourcegraph are working with MCP"
- url: https://www.anthropic.com/news/model-context-protocol
- source_type: primary
- published: 2024-11-25
- confidence: high

### [2] MCP 采用规模（截至 2025-12-09 官方口径）：每月 SDK 下载量超 9700 万次、10000+ 活跃服务器、ChatGPT/Claude/Cursor/Gemini/Microsoft Copilot/VS Code 等主流平台均提供一等公民客户端支持
- quote: "MCP has become one of the fastest-growing and widely-adopted open-source projects in AI: Over 97 million monthly SDK downloads, 10,000 active servers and first-class client support across major AI platforms like ChatGPT, Claude, Cursor, Gemini, Microsoft Copilot, Visual Studio Code"
- url: http://blog.modelcontextprotocol.io/posts/2025-12-09-mcp-joins-agentic-ai-foundation/
- source_type: primary
- published: 2025-12-09
- confidence: high

### [3] MCP 官方 servers 仓库（reference implementations）已获 89508 stars / 11437 forks，但 GitHub/GitLab/PostgreSQL/Puppeteer/Redis/Sentry/Slack/SQLite 等参考服务器已归档并移交厂商/第三方维护，官方改用 registry.modelcontextprotocol.io 作为服务器发现入口
- quote: "This repository is a collection of *reference implementations*... If you are looking for a list of MCP servers, you can browse published servers on the MCP Registry (registry.modelcontextprotocol.io)... The servers in this repository... are not production-ready solutions"
- url: https://github.com/modelcontextprotocol/servers
- source_type: primary
- published: 2026-08-13（数据时点）
- confidence: high

### [4] Anthropic 于 2025-12-09 将 MCP 捐赠给 Linux Foundation 下的定向基金 Agentic AI Foundation（AAIF），该基金由 Anthropic、Block、OpenAI 共同创立，Google/Microsoft/AWS/Cloudflare/Bloomberg 支持，Goose（Block）与 AGENTS.md（OpenAI）同为创始项目
- quote: "Anthropic is donating MCP to the Agentic AI Foundation, a directed fund under the Linux Foundation... co-founded by Anthropic, Block and OpenAI, with support from Google, Microsoft, AWS, Cloudflare and Bloomberg... MCP joins two other founding projects: goose by Block and AGENTS.md by OpenAI"
- url: http://blog.modelcontextprotocol.io/posts/2025-12-09-mcp-joins-agentic-ai-foundation/
- source_type: primary
- published: 2025-12-09
- confidence: high

### [5] MCP 安全缺陷之一：工具描述注入（tool description prompt injection）是协议固有问题——恶意 MCP 服务器可在工具描述中植入指令窃取数据；ForgeCode 实测对 2/4 个 MCP 实现生效，并在 1/10 的生产部署中发现未鉴权端点
- quote: "MCP servers describe their tools using natural language descriptions... if you control the MCP server, you can put whatever you want in those descriptions... this attack vector lives in the protocol itself... Found unauthenticated endpoints in 1/10 production deployments"
- url: https://forgecode.dev/blog/prevent-attacks-on-mcp/
- source_type: community
- published: 2025-06-17
- confidence: medium

### [6] MCP 鉴权长期"自行解决"，直到 2025-06-18 版本才强制 OAuth Resource Server 分类、要求实现 Resource Indicators（RFC 8707）、并移除 JSON-RPC batching；但工具描述注入与供应链风险在协议层仍未解决
- quote: "The latest MCP specification (released June 18, 2025)... OAuth Resource Server classification is now required... Removal of JSON-RPC batching... the core vulnerabilities described above (tool description injection, supply chain risks) remain unaddressed in the protocol itself"
- url: https://forgecode.dev/blog/prevent-attacks-on-mcp/
- source_type: community
- published: 2025-06-18
- confidence: medium

### [7] Google 于 2025-04-09 推出 Agent2Agent（A2A）协议解决"不透明 agent 应用之间的互操作"，现已获 25321 stars / 2568 forks，并于 2025 年 6 月捐赠给 Linux Foundation
- quote: "The Agent2Agent (A2A) protocol addresses a critical challenge... enabling gen AI agents, built on diverse frameworks by different companies running on separate servers, to communicate and collaborate effectively - as agents, not just as tools... Operate without exposing their internal state, memory, or tools"
- url: https://github.com/a2aproject/A2A
- source_type: primary
- published: 2025-04-09（发布）；2025-06（捐赠 LF）
- confidence: high

### [8] A2A 已发布 v1.0（production-ready），由 8 家科技公司代表组成技术指导委员会（TSC：Google、Microsoft、AWS、Cisco、Salesforce、ServiceNow、SAP，后加入 IBM）；v1.0 新增 multi-tenancy、Signed Agent Cards（对 agent 身份/元数据的密码学验证）与多协议绑定（JSON+HTTP / gRPC / JSON-RPC）；最新 release 为 v1.0.1（2026-05-28）
- quote: "The A2A Protocol community today are announcing the release of A2A Protocol v1.0... guided by a technical steering committee with representatives from eight major technology companies... Signed Agent Cards provide cryptographic verification of agent identity and metadata... builds on industry-proven protocols, including JSON+HTTP, gRPC, and JSON-RPC"
- url: https://github.com/a2aproject/A2A/blob/main/docs/announcing-1.0.md
- source_type: primary
- published: 2026（v1.0）；v1.0.1: 2026-05-28
- confidence: high

### [9] 互操作协议开始收敛：IBM 于 2025-03 为 BeeAI 推出的 Agent Communication Protocol（ACP）于 2025-08-29 宣布并入 A2A（Linux Foundation 旗下），ACP 停止独立开发、用户迁移至 A2A
- quote: "ACP is officially merging with the A2A under the Linux Foundation umbrella... the ACP team will be winding down active development and will begin contributing its technology and expertise directly to A2A"
- url: https://lfaidata.foundation/communityblog/2025/08/29/acp-joins-forces-with-a2a-under-the-linux-foundations-lf-ai-data/
- source_type: primary
- published: 2025-08-29
- confidence: high

### [10] A2A 官方将自身定位为 MCP 的补充而非替代："MCP inside agents, A2A between agents"（MCP 做单 agent 的工具/上下文接入，A2A 做 agent 之间的通信协调），多智能体系统通常两者并用
- quote: "MCP and A2A solve different layers of the problem. MCP is commonly used for tool and context integration at the individual agent level. A2A focuses on communication and coordination between agents. In practice, many systems will use both: MCP inside agents, A2A between agents"
- url: https://github.com/a2aproject/A2A/blob/main/docs/announcing-1.0.md
- source_type: primary
- published: 2026
- confidence: high

### [11] AGNTCY（Linux Foundation LF Projects，Cisco 牵头，TSC 含 Cisco/Dell/Google/Oracle/Red Hat）提出"Internet of Agents (IoA)"，提供 discovery（Agent Directory Service 联邦注册表）、identity、messaging（SLIM，已提交为 IETF 草案 draft-mpsb-agntcy-slim）与 observability 四类跨厂商/跨框架基础设施
- quote: "AGNTCY delivers an open-source stack enabling AI agents to collaborate across vendors and frameworks through discovery, identity, messaging, and observability"
- url: https://agntcy.org/
- source_type: primary
- published: 2026（current）
- confidence: high

### [12] Agent 身份/审计：A2A v1.0 用 Signed Agent Cards 做密码学身份验证；AGNTCY identity-spec 提供可验证 Agent Badges（verifiable credential）、支持 DUO/OKTA 等标识符示例并规划 Post-Quantum（后量子）支持；agent 支付则出现 x402（HTTP 402 Payment Required，Coinbase）与 Google Agent Payments Protocol（AP2），并有 A2A x402 扩展（google-agentic-commerce/a2a-x402，549 stars）实现 agent 间链上支付
- quote: "Signed Agent Cards provide cryptographic verification of agent identity and metadata, establishing trust before interaction across organizational boundaries"；"Check our Post-Quantum Support"；"The A2A x402 Extension brings cryptocurrency payments to the Agent-to-Agent (A2A) protocol"
- url: https://github.com/a2aproject/A2A/blob/main/docs/announcing-1.0.md ；https://github.com/agntcy/identity-spec ；https://github.com/google-agentic-commerce/a2a-x402
- source_type: primary
- published: 2025–2026
- confidence: high
