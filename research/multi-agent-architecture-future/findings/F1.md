# F1: 主流多智能体框架与编排范式

## Findings

### [1] 微软 AutoGen 已正式进入 maintenance mode，不再新增功能，官方指向继任者 Microsoft Agent Framework (MAF)
- quote: "AutoGen is now in maintenance mode. It will not receive new features or enhancements and is community managed going forward. New users should start with Microsoft Agent Framework."
- url: https://github.com/microsoft/autogen
- source_type: primary
- published: unknown (README 于 2026-08-13 抓取)
- confidence: high

### [2] Microsoft Agent Framework (MAF) 是 AutoGen 的企业级继任者，仓库于 2025-04-28 创建，支持 Python + .NET 双语言
- quote: "Microsoft Agent Framework (MAF) is the enterprise‑ready successor to AutoGen... gives you enterprise-grade multi-agent orchestration, multi-provider model support, and cross-runtime interoperability via A2A and MCP."
- url: https://github.com/microsoft/agent-framework
- source_type: primary
- published: 2025-04-28 (repo created)
- confidence: high

### [3] MAF 的原生编排范式是图 (graph) 工作流：sequential / concurrent / handoff / group collaboration，并内置 checkpointing、HITL、time-travel
- quote: "Build multi-agent systems with graph-based workflows supporting sequential, concurrent, handoff, and group collaboration patterns; includes checkpointing, streaming, human-in-the-loop, and time-travel"
- url: https://github.com/microsoft/agent-framework
- source_type: primary
- published: unknown (README 于 2026-08-13 抓取)
- confidence: high

### [4] AG2 是 AutoGen 的社区 fork，于 2024-11-11 创建，由原 AutoGen 维护者 Chi Wang 与 Qingyun Wu 主导（志愿者团队）
- quote: "The project is currently maintained by a dynamic group of volunteers from several organizations. Contact project administrators Chi Wang and Qingyun Wu"
- url: https://github.com/ag2ai/ag2
- source_type: primary
- published: 2024-11-11 (repo created)
- confidence: high

### [5] AG2 v1.0 将经典 AutoGen API（`import autogen` / ConversableAgent / GroupChat）整体拆分到独立仓库 ag2ai/ag2-classic（2026-06-26 创建）
- quote: "As of AG2 v1.0, the protocol-driven framework is the top-level package... The classic framework has moved to its own repository — ag2ai/ag2-classic... This repository (`pip install ag2`) no longer ships the `autogen` import name or the classic agent classes."
- url: https://github.com/ag2ai/ag2
- source_type: primary
- published: 2026-06-26 (ag2-classic created)
- confidence: high

### [6] LangGraph 定位为“低层有状态智能体编排框架”，v1.0.0 于 2025-10-17 发布（GitHub tag）
- quote: "LangGraph is a low-level orchestration framework for building, managing, and deploying long-running, stateful agents."
- url: https://github.com/langchain-ai/langgraph
- source_type: primary
- published: 2025-10-17 (v1.0.0 tag)
- confidence: high

### [7] LangGraph 的核心差异化是 durable execution（持久化/可恢复执行）+ 人机协同 + 记忆，代表 DAG/状态机范式
- quote: "Durable execution — Build agents that persist through failures and can run for extended periods, automatically resuming from exactly where they left off... Human-in-the-loop... Comprehensive memory"
- url: https://github.com/langchain-ai/langgraph
- source_type: primary
- published: unknown (README 于 2026-08-13 抓取)
- confidence: high

### [8] OpenAI Agents SDK 于 2025-03-11 发布（repo 创建），定位轻量级多智能体工作流框架，核心原语是 handoffs / agents-as-tools（orchestrator-worker 范式）
- quote: "The OpenAI Agents SDK is a lightweight yet powerful framework for building multi-agent workflows. It is provider-agnostic, supporting the OpenAI Responses and Chat Completions APIs, as well as 100+ other LLMs."
- url: https://github.com/openai/openai-agents-python
- source_type: primary
- published: 2025-03-11 (repo created)
- confidence: high

### [9] CrewAI 是活跃维护中最具星标的“角色扮演式”编排框架（约 57k stars），采用 crews + 流程（顺序/层级）的 orchestrator 范式
- quote: "Framework for orchestrating role-playing, autonomous AI agents"（repo description）；README logo alt="Open source Multi-AI Agent orchestration framework"
- url: https://github.com/crewAIInc/crewAI
- source_type: primary
- published: unknown (于 2026-08-13 抓取)
- confidence: high

### [10] MetaGPT 拥有全场最高星标（约 69.8k）但已明显放缓（last push 2026-01-21），项目主页已转向 atoms.dev，呈现“学术范式 → 产品化”转向
- quote: "The Multi-Agent Framework: First AI Software Company, Towards Natural Language Programming"（repo description），homepage = https://atoms.dev/
- url: https://github.com/FoundationAgents/MetaGPT
- source_type: primary
- published: 2023-06-30 (repo created); last push 2026-01-21
- confidence: high

### [11] MetaGPT 论文（arXiv 2308.00352）奠定“软件公司装配线”式 SOP 多智能体范式（角色分工 + 消息池 + 结构化输出），后获 ICLR 2024 接收
- quote: "MetaGPT: Meta Programming for A Multi-Agent Collaborative Framework"
- url: https://arxiv.org/abs/2308.00352
- source_type: primary
- published: 2023-08-01 (arXiv v1), updated 2024-11-01
- confidence: high

### [12] Magentic-One（微软研究院，2024-11）是 orchestrator-led 通用多智能体系统：单个 Orchestrator 指挥 WebSurfer/FileSurfer/Coder/ComputerTerminal 四个专用智能体，且构建在 AutoGen 之上
- quote: "Magentic-One employs a multi-agent architecture where a lead agent, the Orchestrator, directs four other agents to solve tasks. The Orchestrator plans, tracks progress, and re-plans to recover from errors... Built on AutoGen"
- url: https://www.microsoft.com/en-us/research/articles/magentic-one-a-generalist-multi-agent-system-for-solving-complex-tasks/
- source_type: primary
- published: 2024-11 (HN 首发 2024-11-06)
- confidence: high

## Dead ends
- DuckDuckGo HTML (html.duckduckgo.com) 直接超时/被阻断（HTTP 000），webfetch 亦超时，无法使用 DDG 检索
- Bing 搜索被严重本地化，返回大量中文内容农场（CSDN/知乎/百度百科），有效英文/官方链接极少，仅能用于定位 GitHub 官方 repo
- openai.com 官方 Agents SDK 公告页被 Cloudflare 拦截（"Enable JavaScript and cookies to continue"），改用 GitHub repo README 作为一手来源
- LangGraph 1.0 官方博客 URL（blog.langchain.com/langgraph-1-0）返回 404，改用 GitHub releases API 确认 v1.0.0 精确发布日期
