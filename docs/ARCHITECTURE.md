# MDH 架构总览

## 系统架构

```
用户浏览器 (Chrome / Electron)
┌─────────────────────────────────────────┐
│  React 前端 (端口 5173)                  │
│  3D 虚拟办公室 + WebSocket 客户端        │
└──────────────────┬──────────────────────┘
                   │ WebSocket + REST
                   ▼
┌─────────────────────────────────────────┐
│  Python 后端 (端口 8765)                 │
│  FastAPI + SQLite + WebSocket           │
│                                         │
│  ┌─────────┐ ┌──────────┐ ┌──────────┐ │
│  │会议协调器│ │经验提炼器│ │路由引擎  │ │
│  └─────────┘ └──────────┘ └──────────┘ │
│  ┌─────────┐ ┌──────────┐ ┌──────────┐ │
│  │记忆系统 │ │进化系统  │ │交付引擎  │ │
│  └─────────┘ └──────────┘ └──────────┘ │
│  ┌─────────┐ ┌──────────┐ ┌──────────┐ │
│  │缓存层   │ │RBAC 权限 │ │运维模块  │ │
│  └─────────┘ └──────────┘ └──────────┘ │
└─────────────────────────────────────────┘
```

## 核心模块

| 模块 | 文件 | 职责 |
|------|------|------|
| **数据库层** | `db.py` | SQLite WAL 模式，7 张表，写锁管理 |
| **缓存层** | `cache.py` | TTLCache 内存缓存，自动过期 |
| **Agent 档案** | `agent_profile_manager.py` | 持久档案 CRUD + XP 系统 + 技能等级 |
| **经验提炼** | `experience_extractor.py` | 规则提取 + 自进化 + 有效性追踪 |
| **路由引擎** | `dynamic_router.py` | 五维加权路由 + 技能等级感知 |
| **晋升引擎** | `promotion_engine.py` | 10 部门职业路径 + 自动晋升 |
| **记忆系统** | `agent_memory.py` | 持久记忆 + 自动摘要 + 老化 |
| **交付引擎** | `delivery_engine.py` | Git 交付 + 通知 + 报告 |
| **监控** | `proactive_monitor.py` | 健康巡检 + 风险预警 |
| **协同优化** | `team_synergy.py` | 协同分析 + 瓶颈识别 |
| **知识网络** | `knowledge_network.py` | 规则→资产→技能联动 |
| **运维** | `ops.py` | 数据库备份 + 健康检查 |
| **RBAC** | `rbac.py` | API key 角色分级 |
| **缓存** | `cache.py` | TTLCache 内存缓存 |

## 数据流

```
任务输入 → 分流门(规则引擎) → 会议流程(讨论/投票/执行/审查)
                                    ↓
                              任务完成
                                    ↓
                    ┌───────────────┼───────────────┐
                    ▼               ▼               ▼
              XP 授予          经验提炼          交付引擎
              ↓               ↓               ↓
         技能升级         规则有效性追踪     Git commit
              ↓               ↓               ↓
         路由加成         自进化触发         记忆写入
              ↓               ↓               ↓
         晋升检查         联动更新           报告生成
```

## 数据库表

| 表 | 用途 |
|----|------|
| `agent_profiles` | Agent 持久档案（XP/技能/阶段） |
| `experience_rules` | 经验规则（有效性/进化链） |
| `agent_memories` | Agent 记忆（任务摘要/学习心得） |
| `demotion_log` | 降级日志 |
| `evolution_log` | 进化日志 |
| `delivery_log` | 交付日志 |
