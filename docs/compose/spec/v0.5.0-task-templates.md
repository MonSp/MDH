# v0.5.0 — 任务模板库

## [S1] Problem

用户完成 onboarding 后，面对空白的 CEO Chat 不知道下一步做什么。系统有 15 个子系统和 43 个技能包，但用户需要自己想出任务描述。任务模板库降低使用门槛，让用户一键启动常见任务。

## [S2] Design

### S2.1 模板数据结构

```python
@dataclass
class TaskTemplate:
    template_id: str
    title: str                    # "代码审查"
    description: str              # 简短描述（展示用）
    category: str                 # "development" / "testing" / "documentation" / "devops" / "design"
    difficulty: str               # "简单" / "中等" / "高级"
    task_prompt: str              # 预填的任务描述（发送给 CEO 的完整文本）
    recommended_roles: List[str]  # ["executor", "reviewer"]
    recommended_skills: List[str] # ["code_review", "testing"]
    expected_output: str          # "审查报告 + 改进建议"
    icon: str                     # emoji 图标
    tags: List[str]               # ["代码质量", "审查"]
    usage_count: int = 0
    created_at: str = ""
```

### S2.3 存储与管理

**`backend/task_template_manager.py`**：
- `__init__(data_dir)` — 加载预置 + 用户自定义模板
- `list_templates(category=None)` → List[TaskTemplate]
- `get_template(template_id)` → TaskTemplate
- `create_template(data)` → TaskTemplate（用户自定义）
- `update_template(template_id, data)` → TaskTemplate
- `delete_template(template_id)` → bool（仅用户自定义可删除）
- `increment_usage(template_id)` → None
- 存储：`data/task_templates/custom.json`（用户自定义），预置硬编码在 `onboarding_tasks.py` 同级

**REST 端点**：
- `GET /api/templates` → 全部模板列表（预置 + 自定义）
- `GET /api/templates?category=development` → 按类别过滤
- `GET /api/templates/{id}` → 单个模板
- `POST /api/templates` → 创建自定义模板
- `PUT /api/templates/{id}` → 更新模板
- `DELETE /api/templates/{id}` → 删除自定义模板
- `POST /api/templates/{id}/use` → 记录使用次数

### S2.4 前端 TaskTemplatePanel

**新增 `src/components/office-team/TaskTemplatePanel.tsx`**：

- 卡片网格布局，每个模板显示：icon、标题、描述、难度标签、使用次数
- 类别过滤按钮（development/testing/documentation/devops/design/all）
- 点击模板 → 展开详情（推荐角色、推荐技能、预期输出）
- "使用此模板" 按钮 → 将 task_prompt 填入 CeoChatPanel 输入框
- "自定义模板" 按钮 → 打开创建表单
- 搜索框：按标题/描述/标签搜索

**集成到 CeoChatPanel**：
- 输入框旁添加"📋 模板"按钮
- 点击展开 TaskTemplatePanel（下拉面板或侧边栏）
- 选择模板后自动填入输入框，用户可编辑后发送

### S2.5 使用统计

- 每次用户通过模板发送任务，调用 `POST /api/templates/{id}/use`
- 模板卡片显示使用次数，按热度排序选项
- 使用数据可选接入 Prometheus 指标（`mdh_template_usage_total{template_id}`）

## [S3] Out of Scope

- 模板市场（跨用户共享模板）
- 模板版本控制
- AI 自动生成模板
- 模板导入导出（JSON 文件可手动复制）
