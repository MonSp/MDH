# v0.4.0 — 交互式引导 Onboarding

## [S1] Problem

新用户首次访问 MDH 时面对一个空白的 3D 虚拟办公室，没有任何引导。不知道如何配置 API key、如何发送第一个任务、系统能做什么。这是产品采用的最大障碍。

## [S2] Design

### S2.1 后端 Onboarding 状态追踪

**新增 `backend/onboarding_manager.py`**：

```python
@dataclass
class OnboardingState:
    completed: bool = False
    current_step: int = 0  # 0=not_started, 1=api_key, 2=model_select, 3=first_task, 4=second_task, 5=third_task, 6=completed
    api_key_configured: bool = False
    model_selected: bool = False
    tasks_completed: int = 0
    started_at: str = ""
    completed_at: str = ""

class OnboardingManager:
    def __init__(self, data_dir: str):
        self._path = os.path.join(data_dir, "onboarding_state.json")
        self._state = self._load()
    
    def get_state(self) -> OnboardingState: ...
    def update_step(self, step: int): ...
    def mark_api_key_configured(self): ...
    def mark_model_selected(self, model: str): ...
    def mark_task_completed(self, task_index: int): ...
    def complete(self): ...
    def reset(self): ...
```

**REST 端点**：
- `GET /api/onboarding/state` → 返回当前引导状态
- `POST /api/onboarding/step` → 更新当前步骤
- `POST /api/onboarding/complete` → 标记引导完成
- `POST /api/onboarding/reset` → 重置引导状态

### S2.2 前端 OnboardingWizard 组件

**新增 `src/components/onboarding/OnboardingWizard.tsx`**：

全屏模态引导，6 步：

**Step 1: 欢迎**
- 展示 MDH 产品介绍（"数字员工操作系统"）
- 动画展示核心概念：任务→执行→进化
- "开始配置" 按钮

**Step 2: API Key 配置**
- 输入 DeepSeek API Key
- 验证格式（sk- 开头）
- 保存到 localStorage + 后端
- 支持其他提供商（OpenAI/Anthropic）的展开配置

**Step 3: 模型选择**
- 展示可用模型列表（从后端 GET /api/models 获取）
- 推荐 DeepSeek Chat（默认）
- 显示每个模型的特点和定价

**Step 4: 示例任务 1（简单查询）**
- 预设任务："分析当前项目的目录结构并给出改进建议"
- 展示任务发送 → CEO 分析 → 简单路径执行 → 结果返回的完整流程
- 用户点击"发送"按钮，观察执行过程
- 完成后显示："恭喜！你的第一个数字员工任务已完成"

**Step 5: 示例任务 2（代码生成）**
- 预设任务："为项目创建一个 Python 工具函数，实现字符串格式化"
- 展示任务 → 团队组装 → 执行 → 审查的复杂路径
- 用户观察多 Agent 协作过程
- 完成后显示："你的数字员工团队正在学习和成长"

**Step 6: 示例任务 3（多角色协作）**
- 预设任务："设计一个简单的 REST API 并编写测试"
- 展示完整的会议讨论 + 投票 + 执行 + 经验提炼流程
- 完成后显示进化面板：XP 增加、规则创建、技能提升
- "进入大荒界" 按钮，关闭向导

**OnboardingGuard 组件**：
- 在 App.tsx 中包裹整个应用
- 首次访问时检查 `/api/onboarding/state`
- 如果 `completed === false`，显示 OnboardingWizard
- 完成后不再显示（除非手动重置）

### S2.3 示例任务预设

**新增 `backend/onboarding_tasks.py`**：

3 个预设任务，难度递增：

```python
ONBOARDING_TASKS = [
    {
```

`GET /api/onboarding/tasks` → 返回预设任务列表

### S2.4 引导完成后

- 向导关闭，显示完整 3D 办公室
- 首个任务的进化结果（XP、规则）在进化面板中可见
- 用户可以立即开始使用系统
- "帮助"菜单中保留"重新体验引导"选项

- 视频教程
- 交互式教程叠加（overlay highlighting）
