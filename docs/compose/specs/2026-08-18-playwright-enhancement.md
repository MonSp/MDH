# P4: Playwright 能力深化方案

## 一、TS 端：本地有头浏览器插件化

### 1.1 目标
- 用户可见的浏览器窗口，支持实时观察自动化过程
- 支持浏览器扩展加载（如 React DevTools、Lighthouse）
- 与 HITL 系统集成，关键操作需用户确认
- 支持录制用户操作并回放

### 1.2 架构设计

```
┌─────────────────────────────────────────────────────────┐
│  TS Orchestrator (Node.js)                               │
│  orchestrator/src/toolkit/browser.ts                     │
│                                                          │
│  ┌─────────────┐  ┌─────────────┐  ┌─────────────┐    │
│  │ HeadlessMode│  │ HeadedMode  │  │ PluginMode   │    │
│  │ (服务端)    │  │ (用户可见)  │  │ (扩展加载)   │    │
│  └──────┬──────┘  └──────┬──────┘  └──────┬──────┘    │
│         │                │                │            │
│         └────────────────┼────────────────┘            │
│                          │                              │
│                    ┌─────▼─────┐                       │
│                    │ Playwright │                       │
│                    │   Browser  │                       │
│                    └───────────┘                       │
└─────────────────────────────────────────────────────────┘
```

### 1.3 实现要点

**模式切换：**
- `headless: true` → 无头模式（服务端）
- `headless: false` → 有头模式（用户可见）
- `extensions: [...]` → 插件模式（加载 Chrome 扩展）

**HITL 集成：**
- `navigate` 到非白名单域名需确认
- `fill` 敏感表单（密码、支付）需确认
- `click` 提交按钮需确认
- `evaluate_js` 执行需确认

**录制回放：**
- 记录用户操作序列
- 支持导出为 JSON 脚本
- 支持回放执行

## 二、Python 端：远端无头自动化任务

### 2.1 目标
- 服务端批量执行浏览器任务
- 支持任务队列和并发控制
- 结果持久化和错误重试
- 资源池管理（多浏览器实例）

### 2.2 架构设计

```
┌─────────────────────────────────────────────────────────┐
│  Python Backend                                          │
│                                                          │
│  ┌─────────────┐  ┌─────────────┐  ┌─────────────┐    │
│  │ TaskQueue   │  │ BrowserPool │  │ ResultStore  │    │
│  │ (任务队列)  │  │ (实例池)    │  │ (结果存储)   │    │
│  └──────┬──────┘  └──────┬──────┘  └──────┬──────┘    │
│         │                │                │            │
│         └────────────────┼────────────────┘            │
│                          │                              │
│                    ┌─────▼─────┐                       │
│                    │ Playwright │                       │
│                    │   (无头)   │                       │
│                    └───────────┘                       │
└─────────────────────────────────────────────────────────┘
```

### 2.3 实现要点

**任务队列：**
- 支持批量 URL 抓取
- 支持定时任务
- 支持任务优先级

**实例池：**
- 动态创建/销毁浏览器实例
- 实例健康检查
- 负载均衡

**结果存储：**
- 截图存储到文件系统
- 页面内容存储到数据库
- 支持结果查询和导出
