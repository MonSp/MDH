## 4. 与 DSH 的架构对比

| 维度 | DSH | MDH (当前) |
|------|-----|-----------|
| **插件粒度** | 全栈（模型/工具/session/loop 都是插件） | 技能包 + 路由模块 |
| **Session Log** | append-only 事件溯源 + invariant 断言 | SessionEvent JSONL + deriveMessages |
| **Subagent** | 独立 session + 深度预算 + 进程外桥接 | RoleAgent.spawnSubagent（进程内） |
| **工具执行** | 三段 waterfall + 单调 guard | pre/execute/post + LLM 守卫 |
| **配置** | profile/bundle/patch 三层组合 | roles_config.yaml + SkillBridge |
| **安全** | sandbox = 策略围栏 | HITL 分级 + LLM 守卫 |
| **Context Engineering** | compaction + structured note-taking + multi-agent | SessionEvent + build_experience_summary |
